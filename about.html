About TaskFlow

A lightweight task-management web application built for the DevOps Fundamentals CI/CD assignment.

Purpose

TaskFlow helps you keep track of your day-to-day tasks in one simple place. It lets you add tasks, view them in a list, inspect individual task details, and see an at-a-glance summary on the dashboard. The app is fully containerized with Docker and automatically built and deployed through a GitHub Actions CI/CD pipeline.

How to Use TaskFlow

  • Dashboard – Open index.html to see total, pending, and completed task counts.
  • Add Task – Use the Add Task page to enter a title, description, due date, and priority.
  • Task List – Browse all tasks in a table and filter by All / Pending / Completed.
  • Task Detail – Click any task to view its full details and mark it complete or delete it.
  • About – You are here! This page explains what the app does and how to navigate it.

Behind the Scenes

Every change to a page flows through the pipeline: a feature branch is opened as a Pull Request to develop, the CI workflow builds and pushes a Docker image, and once merged the CD workflow triggers a deployment to Render — delivering the updated app automatically.

Frequently Asked Questions

  • Is my data saved? This is a demo UI, so tasks are illustrative and not persisted.
  • How do I add a task? Open the Add Task page, fill the form, and submit.
  • How do I mark a task done? Open a task's detail page and choose “Mark as Complete”.
